# Agripedia (アグリぺディア株式会社)

> Agripedia is a Tokyo agricultural technology company, founded June 2019 and headquartered in
> Nishi-Gotanda, Shinagawa-ku, that connects mid- and large-scale Japanese farms with food-service and
> food-manufacturing buyers. It supports growers from GAP certification through to the sale of the
> certified produce, runs a B2B direct-sales channel for GAP-certified commercial agricultural
> products, sells crop-protection materials and fertilizer, and operates its own production management
> system for cultivation history and traceability. It holds JGAP group certification (March 2023) and
> is a Ministry of Agriculture, Forestry and Fisheries GAP partner.

## Status

Agripedia publishes **no public API**, no developer portal, no API reference and no machine-readable
contract. As of 2026-09-13, contract discovery was run against every host this company is known to
operate and every probe missed:

- `agripedia.co.jp` is a Nuxt single-page app whose server answers HTTP 200 with the same HTML shell
  for every path, including a random control path. `/openapi.json`, `/openapi.yaml`, `/swagger.json`,
  `/v1/openapi.json`, `/api-docs`, `/api/docs`, `/docs`, `/redoc`, `/graphql`, `/llms.txt`,
  `/apis.json` and all `/.well-known/` paths return that shell, not a document. Its sitemap lists
  exactly two static routes: `/` and `/news`.
- `kanri.agripedia.co.jp` (AP管理システム, a Rails application) answers 401 with a Japanese
  "please register or sign in" body, or 302 to `/users/sign_in`, for every path probed. There is a
  JSON backend behind that wall, but no public contract is published for it.
- `connect.agripedia.co.jp` describes itself in its own meta description as "AgriPedia 社内向けSCM
  システム" — an internal supply-chain system — and is likewise a catch-all SPA shell.
- `material-sales.agripedia.co.jp` returns real hard 404s for every spec, `/llms.txt` and
  `/.well-known/` path.
- No package named `agripedia` exists on npm, PyPI or RubyGems. The company's GitHub organization
  holds one public repository, a static cron-expression converter page, and no API client or spec.
